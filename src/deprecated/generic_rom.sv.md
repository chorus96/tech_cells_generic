# generic_rom.sv

레거시 범용 ROM 행동 모델입니다. 파일에서 초기화 데이터를 로드하는 단순 동기 ROM입니다.

> **Deprecated**: 신규 설계에서는 공정별 ROM 셀이나 초기화된 SRAM을 사용하세요.

## 모듈: `generic_rom`

### 파라미터

| 파라미터 | 기본값 | 설명 |
|----------|--------|------|
| `ADDR_WIDTH` | 32 | 주소 비트 폭. 워드 수 = `2^ADDR_WIDTH` |
| `DATA_WIDTH` | 32 | 데이터 비트 폭 |
| `FILE_NAME` | `"./boot/boot_code.cde"` | 초기화 데이터 파일 경로 (바이너리 형식) |

### 포트

| 포트 | 방향 | 설명 |
|------|------|------|
| `CLK` | input | 클럭 |
| `CEN` | input | 칩 인에이블 (active low) |
| `A` | input | 주소 |
| `Q` | output | 읽기 데이터 |

### 동작

1. **초기화**: 시뮬레이션 시작 시 `$readmemb(FILE_NAME, MEM)`으로 바이너리 파일에서 메모리 로드
2. **읽기**: `CEN=0`일 때 클럭 상승 에지에 주소를 래치(`A_Q`)
3. **출력**: 래치된 주소(`A_Q`)로 메모리 데이터 조합 출력 (`Q = MEM[A_Q]`)

### 쓰기

이 모듈은 읽기 전용입니다. 쓰기 기능이 없습니다.
